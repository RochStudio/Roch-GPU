# Roch GPU 1.0.8

- Fix XBAR/SYS offset reads and writes by selecting the field from the driver control layout. Remove the incorrect RTX 4070/591.86 restriction; fail closed on unreadable or unknown layouts and verify successful writes.
- Add 13 native NVIDIA telemetry readings: video-engine/bus load, available VRAM/usage, video clock, thermal limit, four limiter flags, and PCIe generation/speed/width.
- Correct the instantaneous GPU clock label to measured and retain XBAR/SYS telemetry independently of tuning support.
- Move the light/dark toggle beside Minimize with sun/moon icons matching Roch Viewer.

Validation: 425 core checks and 28 telemetry checks pass. On RTX 4070/591.86, both XBAR and SYS passed +15 → 0 → +15 MHz write/read-back tests; the original +15 MHz offsets were restored. The added sensors were read from that card. This does not establish overclock stability or universal hardware compatibility.

HWiNFO-specific chip temperatures, individual rail readings unavailable in this backend, D3D counters, PCIe errors, normalized power, and interval-averaged effective clocks are not added.

Download `RochGPU.exe`, fully exit the previous window and tray instance, then run the new executable. Windows x64 and a compatible NVIDIA or AMD driver are required. No separate .NET runtime is needed.
