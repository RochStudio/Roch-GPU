# Roch GPU 1.0.9

Intel Arc Pro B60 tuning and telemetry join the existing NVIDIA and AMD backends. This update includes the fan-setting preservation and Graphics-window fixes developed since 1.0.8.

## Changes

- Intel driver-reported voltage, core, memory, power and thermal controls; editable V/F curves; fixed-duty and hardware fan curves.
- Optional core frequency range with profile persistence, factory reset and readback/restore checks. No Arc Power code or binaries are included.
- Editor steps: 5% voltage, 15 MHz core, 100 Mbps memory, 5% power and temperature. Loading preserves existing values.
- Battlemage telemetry: VR temperatures, memory voltage (read-only), GPU/memory power, bandwidth, VRAM usage, PCIe link and throttle state where available.
- Graphics identity: board manufacturer, chip, Xe core count, revision, memory type/width, VBIOS and PCI bus address. Intel driver dates match the installed version. Graphics details scroll at smaller sizes.
- Fan-window applies synchronize back to the main editor, preserving fan settings when power/clocks change.

## Review fixes

- Read-only UI requests and voltage-cap changes use the same service lock as telemetry. A software fan-curve update cannot race a change to fixed/automatic mode.
- A polling shutdown timeout retains the native context rather than unloading a driver library still executing a call. Cancellation resources are disposed after the poll stops.
- Stock profiles obtain voltage limits from driver metadata (0% on the tested B60); no assumed Intel default is used.
- Vendor P/Invoke DLL discovery is restricted to System32, including the vendored NVAPI entry points.
- Unavailable first-sample CLI sensors display a dash. Intel voltage is labelled as a limit.
- Setup delegates to the standard build script; core, telemetry and app tests run before publishing.

## Validation

- Release build/publish: zero warnings and errors.
- 488 core checks, 34 telemetry checks, 23 app checks: **545 passed**.
- Regression coverage includes defaults after reset, profile/fan persistence, concurrent UI/telemetry access, stalled-poll shutdown, DLL search policy, and Graphics row binding, scrolling and theme resources.
- Published executable: mock info smoke test; read-only Intel Arc Pro B60 identity, sensors and diagnostics on driver 32.0.101.9030. File version 1.0.9.0.
- Earlier scoped B60 tuning tests are documented in [Intel validation](../intel-arc-b60.md) and [clock-range validation](../intel-clock-range-validation.md). No new physical tuning writes or stress tests were performed for this review.

The review covered the tuning/service lifecycle, profile and startup paths, native bindings, UI/CLI integration, telemetry models, build workflow and new Intel implementation. All first-party projects were built and regression-tested. This is not an exhaustive third-party source audit or proof that every GPU/driver combination works. NVIDIA/AMD hardware was not available for fresh live tests; Intel memory voltage remains monitoring-only. Manual visual verification is separate from the automated WPF layout checks.

## Build

Run `./build.ps1` with the .NET 10 SDK on Windows. The combined GUI/CLI executable is `dist/RochGPU.exe`. Exit any older window and tray instance before switching builds. Source updates do not automatically publish a GitHub Release.
