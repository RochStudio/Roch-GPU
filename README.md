# Roch GPU

A native Rust tuning and monitoring tool for NVIDIA, AMD and Intel Arc GPUs on Windows.

**[Download for Windows](https://github.com/RochStudio/Roch-GPU/releases/latest)**

Run `RochGPU.exe` and allow administrator access when prompted.

- GPU tuning, fan controls, live telemetry and saved profiles.
- Custom themes, colours, fonts and layouts through the Settings gear.
- One executable. No .NET or HWiNFO required.

Support varies by GPU and driver. See the [technical guide](docs/development.md#verification-status) for hardware validation and tuning limitations.

Build from source with Rust stable:

```console
cargo xtask build
```
